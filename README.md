# Overview

This project is designed for the course of Agentic Software Engineering in School of Computer Science (CS3604) and Global College (CSXXXX) in Shanghai Jiao Tong University, for students to understand general workflow of software engineering and implement the workflow in an agentic manner.

# Outline (16 weeks)

1. **Agentic Software Engineering and Requirement Compilation**: This course will brief why we need software engineering (rather than just programming) and how we are to build agentics to automate the whole software engineering workflow.
2. **The Foundation of Web Development**: This course will help the students have hands-on experience to build a web system, including frontend and backend, as long as database system, with modern development framework such as Vue and NodeJS. If with no experience, you will build your first non-trivial web system after this course.
3. **LLM, RAG, and MCP**: This course will show the working principle of Large Language Model, demonstrate its hallucination, and how to mitigate the potential hallucination with more enriched context and tool calling strategy.
4. **Requirement Engineering and Test-Driven Development**: This course will introduce how to write sufficient software requirements/documents, not just for human but also for agents, what is test-driven development, and how the agentic-driven requirements can facilitate agentic test-driven development paradigm. After the course, the students are expected to compile a non-trivial requirment document into a runnable web system.
5. **Version Control System (Git)**: This course will introduce how the Git version control system works.
6. **Requirement Compilation and Traceability**: This course will introduce how to enhance the exisitng requirement compilation workflow by incoporating Git tool and generating relevant software traceability.
7. **Software Testing**: This course will introduce black box and white box testing.
8. **Software Evolution**: This course will introduce how the requirement can evolve in a non-trivial way and how Agentic Requirement Compilation can facilitate the evolution.
9. **Continuous Integration and Deployment**: This course will introduce how existing facilities such as Github Action can help check the unexpected errorous commits and how a system can be deployed in a continuous manner.
10. **Practice (Feature Enhancement)**: The students are to include a new feature in existing system during the course.
11. **Practice (Feature Enhancement)**: The students are to include a new feature in existing system during the course.
12. **Practice (Testing, Debugging, and Repairing)**: The students are to find and fix a bug in existing system during the course, with learned testing approaches.
13. **CA (Feature Enhancement, with score)**: The students are to include a new feature in existing system during the course.

In addition, we expect a mid-term presentation and final presentation during the course.
